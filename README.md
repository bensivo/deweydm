# Dewey Data Manager
A fully configurable data management system that adapts to your needs—like a CRM, ERP, or project management tool that you always wish you had.

## Packages

- `webapp/` — Angular frontend.
- `electron/` — Electron main process, SQLite-backed services, IPC handlers.
- `cli/` — Command-line interface that talks to the same SQLite DB as the Electron app. See [`cli/README.md`](./cli/README.md).
